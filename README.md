# Music Genre Classification Application

Classifies music audio into one of ten genres using deep learning on the GTZAN dataset.

**Genres:** blues, classical, country, disco, hiphop, jazz, metal, pop, reggae, rock

## Features

- Train the genre classification models
- Evaluate trained models (reports, confusion matrices, ROC-AUC, embeddings)
- Predict the genre of a `.wav` or `.mp3` file
- Run a demo using random dataset samples
- Streamlit web interface for prediction, evaluation, and training

## Models

| Model | Description |
|---|---|
| **CNN Baseline** | Predicts genres from audio segments and combines the segment predictions |
| **CNN+LSTM** | Uses the CNN features with an LSTM sequence model for song-level prediction |

## Requirements

- Python 3.9 or newer
- pip
- A terminal or command prompt

Install dependencies:

```bash
pip install -r requirements.txt
```

Main packages: `torch`, `torchaudio`, `numpy`, `scikit-learn`, `soundfile`, `matplotlib`, `pandas`, `seaborn`, `librosa`, `rich`, `streamlit`, `kagglehub`.

`torch` and `torchaudio` are pinned to matching versions and must stay matched, otherwise audio loading may fail:

```text
torch==2.7.0
torchaudio==2.7.0
```

## Getting Started

### 1. Clone and install

```bash
git clone <your-repo-url>
cd <your-repo-folder>
pip install -r requirements.txt
```

### 2. Get the dataset

The project uses the [GTZAN music genre dataset](https://www.kaggle.com/datasets/andradaolteanu/gtzan-dataset-music-genre-classification). If `kagglehub` is available, the training pipeline can download it automatically. Otherwise, place it manually so the structure is:

```text
data/genres_original/
├── blues/
├── classical/
├── country/
├── disco/
├── hiphop/
├── jazz/
├── metal/
├── pop/
├── reggae/
└── rock/
```

### 3. Train the models

The trained models are not stored in this repository, so train them first:

```bash
python main.py --train
```

This trains both models and runs a hyperparameter search first. For a faster run with default settings:

```bash
python main.py --train --no-hp
```

Training creates:

```text
models/best_cnn.pt
models/best_frozen_cnn_lstm.pt
```

Evaluation, prediction, demo mode, and the web app's prediction and evaluation pages all require these files.

## Usage

### Interactive menu

```bash
python main.py
```

```text
1. Train both models - full pipeline
2. Train - skip hyperparameter search
3. Evaluate saved models
4. Predict genre of an audio file
5. Demo mode
6. Exit
```

### Command-line options

| Command | Action |
|---|---|
| `python main.py --train` | Train both models with hyperparameter search |
| `python main.py --train --no-hp` | Train both models, skipping hyperparameter search |
| `python main.py --evaluate` | Evaluate saved models; plots are saved to `plots/` |
| `python main.py --predict "path/to/song.wav"` | Predict a genre with the CNN model |
| `python main.py --predict "path/to/song.wav" --model lstm` | Predict a genre with the CNN+LSTM model |
| `python main.py --demo` | Predict genres for random dataset samples |

Supported input formats: `.wav`, `.mp3`.

### Web application

```bash
streamlit run app.py
```

**Predict & Playground**
- Upload an audio file or choose a GTZAN test sample
- Select CNN or CNN+LSTM
- View the predicted genre, confidence scores, spectrogram, and segment-level probabilities

**Model Evaluation**
- Performance tables, classification reports, confusion matrices, ROC-AUC plots
- Genre-wise performance, feature embedding plots, final model comparison
- Results are cached in `plots/streamlit_evaluation_cache.pkl`; press **Re-evaluate** to delete the cache and run the evaluation again

**Training Panel**
- Choose training settings, start training, monitor progress, and save updated checkpoints

## Files Generated by the Program

| Path | Contents |
|---|---|
| `models/` | Saved model checkpoints |
| `cache/spectrograms/` | Cached processed audio segments (speeds up repeat runs) |
| `cache/temp_uploads/` | Temporary files from web app uploads |
| `plots/` | Evaluation images |
| `plots/streamlit_evaluation_cache.pkl` | Cached Streamlit evaluation |

All of these are recreated automatically when you run the program.

## Typical Workflow

```bash
pip install -r requirements.txt
python main.py --train       # train (downloads/uses the dataset)
python main.py --evaluate    # evaluate
streamlit run app.py         # launch the web app
```
